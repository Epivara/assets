Desktop Scheduling

The desktop app can manage the same cloud tasks as the web app, but it can also run tasks on your computer. Use a local task when ChatGPT needs files or a project that you have not uploaded.

Cloud or this device?

  • Cloud — runs even when your computer is off. Tasks created on the web appear in the desktop app as cloud scheduled tasks.
  • This device — can work with local files and projects, but the computer must be on with ChatGPT running when the task is due.

Choose Cloud unless the task needs something stored on your computer.

Creating a local task

Open Scheduled in the desktop app and create a task. Choose This device, then enter the prompt and schedule.

You can also choose:

  • Whether each run continues an existing chat or starts a new one.
  • Which Project should hold a new chat.
  • The model and reasoning level.
  • Whether to receive important updates, failed-run notifications, or both.

Cloud tasks use the simpler web setup, so most of these options only appear when This device is selected.

Local means local

If the computer is asleep, the app is closed, or the selected folder is unavailable, a local task cannot run as planned. Use a cloud task when you do not need local files.

For the basic workflow, including editing, pausing, and reviewing tasks, see Scheduled Tasks.
