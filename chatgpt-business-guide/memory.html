Memory

ChatGPT can remember things about you from one conversation to the next — who you are, what you're working on, and how you like things done — so you don't have to re-explain yourself every time. It builds this up quietly as you chat, and you stay in control of it.

What it remembers

Placeholder: as you use it, ChatGPT saves small notes about you — your role, projects you bring up often, preferences you state (“keep replies short,” “always use metric”), and other recurring details — then leans on them in later chats without being asked.

Managing your memory

Placeholder: you're not stuck with whatever it decides to keep. In Settings you can see everything ChatGPT has remembered, edit or delete individual memories, or turn memory off entirely. If it ever picks up something wrong or out of date, this is where you fix it.

It gets better the more you use it

Early on, ChatGPT can feel a little janky — it assumes things, or takes a roundabout path to what you actually wanted. That's normal at the start. Memory, together with clear prompting, is how you steer it: correct it once, tell it how you'd prefer things done, and it carries that forward. Building up memory is gradual, so it can seem like a novelty at first — but the more you use it, the more it shapes itself around how you actually work.
