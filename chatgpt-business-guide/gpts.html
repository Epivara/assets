GPTs

A GPT is a saved version of ChatGPT with its own instructions, files, and tools — the same idea as an agent. GPTs came first, and in OpenAI's words, “Workspace agents are an evolution of GPTs.”

So if you're setting something up for yourself, build an agent. This page is here so you know what the GPTs page in the sidebar is, and when a GPT is still the better pick.

How they differ

An agent can go off and do work on its own, including on a schedule. A GPT only ever responds when you talk to it. Otherwise the two are much the same: instructions, files, and apps it can use.

GPTs don't use your memory

A GPT works only from its own setup. It has no access to ChatGPT's memory or to your other conversations, so anything it needs to know has to be in its instructions, its files, or the chat itself.

When a GPT is still the better pick

  • You want to use it in the desktop app. Workspace agents can't be chatted with there, but GPTs can be tagged and used like normal.
  • Someone already built one. If a GPT in the catalog already does what you need, there's nothing to set up.

Using GPTs

On the web, open the GPTs page from the sidebar. From there, pick a GPT that someone else has already built, or create your own — setting one up works much the same as creating an agent.
