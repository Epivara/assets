ARTisto Usage Guide

What is ARTisto?

ARTisto is an extension built for QuPath, the digital pathology platform.

ARTisto gives the user access to custom trained AI models specialized in testes histology to aid in pathological analysis. It uses these AI models to segment objects of interest and return mathematical measurements.

At this time, ARTisto offers three "modules":

  • Tubule
  • Leydig cell
  • Spermatogenesis

Each module specializes in finding different objects and returns module-specific metrics.

To get started using ARTisto, continue onto setup.

Using a mouse is recommended!

Note: ARTisto was formerly named ReproPath, so you may still see the ReproPath name in some images throughout this guide.
