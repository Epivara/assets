ReproPath Usage Guide

What is ReproPath?

ReproPath is an extension built for QuPath, the digital pathology platform.

ReproPath gives the user access to custom trained AI models specialized in testes histology to aid in pathological analysis. It uses these AI models to segment objects of interest and return mathematical measurements.

At this time, ReproPath offers three "modules":

  • Tubule
  • Leydig cell
  • Spermatogenesis

Each module specializes in finding different objects and returns module-specific metrics.

To get started using ReproPath, continue onto setup.

Using a mouse is recommended!
