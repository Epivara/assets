Setup

Installing QuPath

QuPath (version ≥ 0.6.0) must be installed to start using the ReproPath extension. QuPath can be installed from their website.

Once QuPath is installed, open QuPath and finish initial setup.

Layout

The QuPath window will look as such:

The menu bar contains the Extensions menu from which you can access the ReproPath extension once installed. The View menu provides viewer options that may be helpful, such as adjusting brightness.

The image viewer shows you the currently opened image, allowing you to pan and zoom.

The tool bar contains annotation tools and settings for working in the viewer.

The left sidebar houses multiple tabs with different purposes.

Installing the extension

Have the extension .jar file downloaded.

To install the ReproPath extension, drag and drop the jar file onto the QuPath window. Alternatively, select Extensions → Manage extensions from the menu bar to open the Extension Manager, then press Open extension directory. Place the jar file into this directory.

Check that ReproPath is installed by finding Extensions → ReproPath in the menu bar.

To reinstall/update simply delete the old jar and add the new one. To delete the old jar, open the Extension Manager, find the jar, and press the Delete extension button. Or, delete the jar directly from the extension directory.

ReproPath setup

You must log in to use ReproPath.

Open the ReproPath menu by navigating to the menu bar and selecting Extensions → ReproPath → Open ReproPath.

This will open the ReproPath menu. Press Login at the top to open a login prompt in the browser.

Epivara users should select the Continue with Google option and use their company Google login.

Outside users should create a new account my pressing Sign up. If you are denied access, contact an Epivara administrator to have an account created.

Setting up Cloud Slide viewing

Slide image files can be large and unwieldy; the ReproPath extension provides a way to stream slide images from an AWS S3 bucket. Other connections are not supported at this time.

Set up the connection by navigating to the menu bar, Extensions → ReproPath → Open from Cloud. This opens the Open from Cloud menu with a form to specify a connection.

For the Epivara jar, this form should come populated with defaults pointing to Epivara's slide image store. If the connection is valid, pressing Sign in with AWS will open a browser tab prompting a login through whatever authentication service is set up.

The Epivara slide storage uses the AWS IAM Identity Center for authentication; it has been populated with Google logins from Epivara's Google organization. Proceed to login with your Epivara company email, completing any account setup required.

For outside users, set up and connect your own AWS S3 cloud storage, or contact an Epivara admin to create a user for you.

Once logged in, you should have access to cloud-hosted slide images in the Open from Cloud menu, which you can view and add to your projects.

Disclaimer: Only .tiff images are supported at this time.
